# Dom Cray — site oficial

Portfólio estático publicado no GitHub Pages pela branch `main`, na raiz do repositório.

- `index.html`: capa editável, história em primeira pessoa, discografia, shows, aulas e contato.
- `assets/site.css`: estilos do projeto aprovado.
- `assets/refinements.css`: tipografia, composição e adaptações para celular.
- `assets/site.js`: menu, galeria ampliável, vídeos e formulário que abre um rascunho no WhatsApp.
- `assets/colagem-fotografica-dom-cray.png`: colagem fotográfica fornecida, sem textos e botões.
- `assets/fonts/`: fontes locais e suas licenças.
- Os dois arquivos `show-ao-vivo-*.mp4` são os registros originais de apresentações.

A capa completa em `images/` é preservada como referência e imagem de compartilhamento. Textos, menu, botões e quadros da página são elementos HTML independentes.

Links de streaming, créditos detalhados, letras, novas datas e PDFs técnicos aguardam confirmação; o site sinaliza essas pendências sem criar links fictícios.

Publicação: https://priscilacodemy-star.github.io/dom-cray-oficial/
